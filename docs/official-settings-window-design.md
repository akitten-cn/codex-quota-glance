# 官方登录设置窗口设计

## 目标

为 Codex Taskbar 提供一个只在用户主动打开时运行的 Rust 原生设置窗口。它取代已删除的手写 Win32 自绘设置页，重点解决点击失效、滚动残影和高 DPI 可读性问题。

## 技术选择

- 使用 Slint + Rust，而不是 WebView2、TypeScript 或 Electron。
- 设置窗口是独立可执行文件 `codex-taskbar-settings.exe`，关闭即退出；常驻任务栏仍保持现有 Win32/Direct2D 实现。
- 指定 Windows Winit + 软件渲染后端，不依赖 Qt、浏览器运行时或常驻 GPU 进程。
- 主程序通过启动独立设置进程打开窗口；设置进程只读写 `settings.json`，保存后向同目录写入一个不含敏感信息的 reload 通知文件。主程序低频检查该文件并重载配置。

选择 Slint 的原因是它提供 Rust 声明式布局、可靠滚动和可访问原生输入控件；其 Winit 后端可在 Windows 使用，且可只选择特定后端以缩小构建。官方文档：<https://docs.slint.dev/latest/docs/rust/slint/docs/cargo_features/>。

## 配置边界

窗口仅编辑官方登录版 `AppConfig`：

1. 任务栏：目标屏幕、左右停靠、宽度、安全间距、TrafficMonitor 偏移。
2. 显示内容：状态灯、额度环、倒计时、今日 Token、缓存命中率等项目的显示与顺序。
3. 体验：减少动画。
4. 诊断：日志等级、可选 Codex CLI 路径。

不展示、不保存、不迁移 New API、API Key、账户 token 或第三方价格信息。

## 交互设计

- 深色现代简约界面：左侧窄导航，右侧内容卡片；圆角、低对比边框、系统字体。
- 页面为“任务栏”“显示内容”“诊断与关于”三项；内容区使用单一 ScrollView，避免嵌套滚动。
- 所有输入都具备清晰 hover/focus 状态，保存按钮固定于窗口底部。
- 点击“恢复默认”只重置窗口草稿，不立刻落盘；保存成功后显示短暂成功反馈。
- 保存前做范围校验；保存失败时在窗口内显示可读错误，不退出、不覆盖原文件。

## 一致性与即时应用

1. 设置进程打开时读取并规范化 `settings.json`，形成独立草稿。
2. 保存时用现有 `AppConfig::save_atomic` 原子替换 JSON。
3. 保存成功后写入 `settings.reload`，内容只包含版本号和保存时间。
4. 常驻程序最多每秒检查一次该通知；发现后重新读取配置、重新加载日志等级、重新计算任务栏位置和显示模型。
5. 通知文件处理完成后删除。通知丢失时用户可从托盘菜单选择“重新加载设置”。

## 验收

- 100%、150%、200% 缩放下可以点击所有控件，文本不残留、不裁切。
- 长列表可平滑滚动；滚动后不出现旧文字残影。
- 保存可立即改变任务栏的停靠位置、宽度、显示项和动画；无效输入不写盘。
- 独立窗口关闭后不留下 Slint、WebView 或浏览器类常驻进程。
- `cargo test --workspace`、Clippy、格式检查、release 构建均通过；对设置窗口进行一次真实截图/交互验收。
