# 视觉里程碑 V1

## 目标

- 在 Windows 任务栏中稳定显示一套紧凑、透明、可读的主 UI。
- 以任务栏为主展示面，优先提供周额度、运行状态和最小摘要信息。
- 保持与当前原生 Direct2D/DirectWrite 实现一致，不引入 WebView2 或复杂面板系统。

## 预览模式说明

- --visual-preview 仅用于视觉验收（visual QA / visual preview）。
- 该模式使用固定样例状态渲染真实任务栏宿主，用于检查透明背景、圆环、文字和点击交互。
- 该模式不读取生产运行链路，也不向生产状态注入任何样例数据。

## 非目标

- 不在本里程碑内实现完整设置页。
- 不在本里程碑内实现可拖拽排序的任务栏项编辑器。
- 不在本里程碑内实现真正的悬浮详情窗、托盘菜单或历史图表。
- 不在本里程碑内实现 macOS 或跨平台 UI。

## 最终任务栏布局规格

当前实现对应的任务栏布局从左到右如下：

1. 状态灯：
   - 固定宽度 `16 DIP`
   - 保持光晕
   - Idle / Completed 为短暂呼吸后静止
   - Thinking / Executing / Reviewing 持续呼吸

2. 周额度圆环：
   - 主体约 `30 DIP`
   - 垂直居中
   - 外环永远表示 `Weekly`
   - `5h` 存在且 fresh 时显示内环；Absent / Unknown 时不显示内环
   - 圆弧端点为圆角
   - 轨道为轻量半透明描边

3. 圆环中心文本：
   - 显示 `Weekly` 剩余额度百分比
   - 有值时显示 `xx%`
   - 无值时显示 `?%`

4. 右侧两行紧凑摘要：
   - 第 1 行：`状态 + Token`
   - 第 2 行：`5h`
   - 文字直接绘制在透明背景上
   - 不绘制底板、不绘制独立容器边框

## 信息优先级

任务栏主界面的信息优先级按如下顺序排列：

1. 周额度圆环与中心百分比
2. 状态灯颜色、光晕和呼吸反馈
3. 右侧第 1 行摘要中的状态与本线程 Token
4. 右侧第 2 行摘要中的 `5h` 信息
5. 点击后弹出的最小详情文本

当前实现明确以 `Weekly` 为视觉主语，`5h` 只作为嵌套补充，不与主环争夺主层级。

## 交互

- 左键点击任务栏组件：
  - 弹出最小详情对话框
  - 内容来自 `NativeHostDetails`

- 右键点击任务栏组件：
  - 当前与左键行为一致，也弹出最小详情对话框

- 透明区域：
  - 当前窗口整体接收点击，不再使用全窗口 click-through
  - 仍保持逐像素透明背景，只是不再把命中全部转发给下层任务栏

## 验收标准

- 背景必须保持透明，只显示状态灯、圆环和文字。
- 主圆环尺寸明显小于早期探针版本，中心百分比清晰可读。
- 状态灯宽度收紧到约 `16 DIP`，不会再抢占主要空间。
- `Weekly` 百分比必须显示在圆环中心，而不是单独悬浮在旁边。
- 右侧摘要必须稳定显示两行，不出现额外背景块。
- 左键和右键点击都必须能弹出最小详情。
- `5h` 缺失时不显示内环，且右侧第二行仍能反映 `5h` 状态。
