# 产品需求说明（PRD）

- 文档版本：0.1
- 目标平台：Windows 10 / Windows 11
- 产品定位：常驻任务栏的 Codex 活动、额度与 Token 信息监视器

## 1. 产品目标

用户在不切换窗口的情况下，从任务栏持续查看 Codex 是否正在运行、是否等待操作、5h/周额度、重置时间和可选 Token 信息。程序应尽量降低常驻内存、空闲 CPU、启动时间和安装包体积，同时保留足够的诊断能力。

## 2. 显示形态

### 2.1 任务栏信息条（主界面）

- 支持主屏和副屏，按显示器设备 ID 保存位置。
- 支持 Left/Right 锚点、宽度、安全间距、手动偏移和 TrafficMonitor 预留空间。
- Right 必须位于通知区域、时钟和系统状态图标左侧；Left 必须避开开始菜单、搜索和小组件。
- 用户可选择显示项及排列顺序；空间不足时按保留优先级折叠。
- Explorer 重启、显示器插拔或 DPI 变化后自动重新发现并安全恢复。

### 2.2 托盘与桌面浮窗（回退入口）

- 任务栏嵌入失败时，托盘仍能打开设置、刷新、诊断和退出。
- 桌面浮窗作为兼容回退，不与任务栏实现共享窗口坐标状态。
- 默认任务栏窗口是 Explorer 子窗口，不使用全局 TOPMOST；挂接失败时进入托盘/桌面浮窗回退。
- 背景采用 layered per-pixel alpha，未绘制区域必须为完全透明，只保留额度环、文字和状态灯元素。

## 3. 额度圆环

- 使用单个嵌套圆环组件，不显示两个分离圆圈。
- 外环表示周额度，内环表示 5h 额度，统一表达“剩余百分比”。
- 官方完整快照明确缺少 5h 时，内环完全隐藏，外环自动居中/增粗，不保留空占位。
- 额度数据为 stale/unknown 时，不绘制伪实时进度；可显示低干扰的数据不可用标识。
- 颜色阈值可配置，首版默认：充足为绿色、中等为橙色、低额度为红色。

## 4. 活动状态灯

状态灯由实心核心和柔和光晕构成：

| 状态 | 颜色 | 动画 |
|---|---|---|
| Idle | 绿色 | 呼吸 3 秒后静止，保留光晕 |
| Completed | 绿色 | 呼吸 3 秒后静止，保留光晕 |
| Thinking | 蓝紫色 | 持续慢呼吸 |
| Executing | 青色 | 持续呼吸 |
| Reviewing | 青色 | 持续呼吸 |
| WaitingForUser | 橙色 | 静止高对比光晕 |
| Failed | 红色 | 静止高对比光晕 |
| Unknown | 灰色 | 无动画、无或弱光晕 |

- 动画必须基于状态进入时间，而不是每次刷新重新开始。
- 静态状态不得保持动画定时器，避免空闲 CPU 消耗。
- 后续提供“减少动画”设置，开启后所有状态直接显示静态光晕。

## 5. 可配置显示项

首版模型支持：状态灯、嵌套额度环、重置倒计时、当前线程 Token、今日 Token、输入 Token、输出 Token、缓存命中率和数据新鲜度。用户可以：

- 显示或隐藏；
- 拖动或按序号排序；
- 设置任务栏总宽度；
- 设置空间不足时的保留优先级。

## 6. 数据准确性

- 5h/周额度优先使用 Codex App Server 完整快照。
- 活动状态优先使用 thread/turn/item 生命周期事件，前台窗口检测仅作为独立 Focused 信息。
- Token 优先使用 `thread/tokenUsage/updated` 和 `account/usage/read`。
- 最近 Turn 结束并进入等待、完成或失败边界时，Token 快览自动升起，约 4 秒后关闭；重复快照不得反复弹出。
- 官方模式的金额优先展示 App Server 返回的 `estimatedUsageUsdMicros`，必须明确标为估算值而非 Codex/ChatGPT 订阅账单；New API 继续使用用户配置的手动换算比例。
- Codex SQLite 只读访问仅用于兼容与诊断；程序绝不写入 Codex 数据库。
- 权威来源的 absent 不能被旧 session 数据覆盖。
- UI 必须区分 Fresh、Stale、Unknown、Absent，禁止用旧数据冒充实时数据。

## 7. 日志与诊断

- 日志等级：Off、Error、Warn、Info、Debug、Trace。
- Debug 构建默认 Debug，Release 构建默认 Info；设置中可以热更新。
- 文件日志使用结构化 JSONL 和滚动文件；Debug 构建同时输出可读控制台日志。
- 默认不记录认证信息、API Key、提示词正文、工具参数正文和完整用户路径。
- 后续支持脱敏诊断包导出，便于用户反馈 Bug。

## 8. 非功能目标

以下为 P0/P1 的工程目标，不是尚未实测的承诺值：

| 指标 | 目标 |
|---|---:|
| 主程序空闲 Working Set | 8–18 MB |
| 含独立 App Server 总内存 | 25–60 MB |
| 静态空闲 CPU | < 0.1% |
| 动画期间 CPU | < 0.5% |
| Portable ZIP | 3–8 MB |
| 安装包 | 4–12 MB |
| 冷启动到任务栏可见 | < 500 ms（不等待网络） |

## 9. 首版范围外

- macOS/Linux；
- 多 AI Provider 插件系统；
- 额度预测、任务预算建议和复杂历史图表；
- 浏览器 Cookie 抓取、网页 DOM 抓取；
- 向 Codex SQLite 写入任何数据。
