# 今日模型用量与 Windows 安装版

## 数据与界面

- 详情卡片左侧账户信息下方显示“今日模型用量”，只显示本机当天实际捕获的模型，按 Token 总量降序排列。模型名称独占一行，下一行显示 Token 与金额；列表及侧栏在空间不足时可滚动。
- Token 总量使用输入＋输出；缓存输入属于输入的子集，不再叠加。
- 模型 Token 显示采用 K/M/B，最多一位小数；数据库保留完整整数，不改变统计精度。
- 金额采用每条事件的已知官方 API 等价估算，再按模型求和，不代表订阅账单。
- 未知价格显示“暂无法估算”；只有部分事件可估价时标记“部分”，不冒充完整金额。
- 模型缺失的实际事件归入“未识别模型”。没有原始明细的旧聚合量不能凭空拆到具体模型。
- 新增 SQLite 表 `usage_model_daily(day_key, model, total_tokens, cost_micro_usd, unpriced_tokens)`，主键为日期和模型。金额为微美元整数。
- 与现有日/小时桶同事务批量保存；跟随历史保留策略清理。启动完整回扫替换当天模型桶，实时事件增量累加；跨日查询仅显示新日期。
- 只存模型名和聚合数字，不存会话内容、线程 ID 或认证字段。旧 JSON 仅承担旧版迁移，不是新模型统计存储格式。

## Windows 安装包

运行 `scripts/package-installer.ps1`，使用 Inno Setup 6 生成 `codex-taskbar-版本-windows-x64-setup.exe` 及 SHA-256 校验文件。

- 默认安装到 `%LOCALAPPDATA%\Programs\CodexTaskbar`，无需管理员权限。
- 提供开始菜单入口、可选桌面快捷方式、Windows 卸载入口。
- 数据仍在 `%LOCALAPPDATA%\CodexTaskbar`，卸载保留设置与历史。
- 所有 Windows WebView2 创建入口明确指定同一 AppData 缓存目录，避免在桌面或程序旁创建 `.exe.WebView2` 目录。
- 便携包仍可作为备用下载；现有独立 EXE 更新资源保留兼容。本次没有替换现有跨平台自动更新协议。
