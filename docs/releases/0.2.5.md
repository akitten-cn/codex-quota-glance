# Codex Taskbar 0.2.5

本版修复多任务采集、历史账本保护和断线恢复问题，改进 Windows 与 macOS 共用的用量统计逻辑。

- 按文件增量采集所有已发现的任务，覆盖旧任务继续使用和并发任务；隔离模型上下文，避免尾部重读重复计费。
- 修复跨日、空扫描、日志半行补齐和 SQLite/session 来源交接时的重复累计或漏计，保留无法分解的历史总量。
- 账本读取失败时停止本次启动，避免空账本覆盖原历史；持久化清理截止时间和迁移标记，清理写入失败会保留原记录并提示重试。
- 修复断线重连后额度 revision 被拒绝，以及额度端点失败后旧值仍显示实时的问题。
- 按自然日执行历史保留；历史总量汇总全部保留记录，图表仍展示最近14个日桶。
- Windows 支持自定义 CODEX_HOME，并重新发现升级后的本机数据库；增加按应用数据目录的单实例保护。
- 升级先准备完整新文件，替换或启动失败时恢复旧版；成功启动后仍保留旧版备份。
- 保留并统一今日卡片、任务栏和趋势的本机账本展示。

本地及独立复审的工作区测试均为302项通过、1项原有外网测试忽略；发布流水线另行验证各平台构建。

请先退出旧版再安装。聚合历史不能证明缺失日志的逐事件完整性；本版不会自动纠正所有存量错误。API等价金额不是订阅账单。大型目录性能、真实更新异常恢复及部分平台交互仍需进一步实机验收。macOS包为ad-hoc签名，未进行Apple公证。
