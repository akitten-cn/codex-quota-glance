# Codex Taskbar 0.2.6

本版修复 Windows 更新入口、GitHub 限流处理和 Mac 日志记录，并补齐 Mac 应用内更新检查与安装包下载。

- Windows 内置默认发布仓库，修复本地构建点击更新时提示“发布仓库尚未配置”。
- 更新请求重新读取当前用户的系统代理，静态代理显式绑定，继续兼容 PAC/WPAD；检查和下载共用代理逻辑。
- 区分 GitHub API 限流与普通访问拒绝。API 返回 403/429 时尝试官方 Release 校验清单，仍强制校验安装包 SHA-256。
- Mac“检查更新”显示实际版本检查结果；“下载并打开安装包”按架构下载 DMG/ZIP，校验后打开本地包，供手动完成安装。
- Mac 增加启动、连接状态、设置保存、诊断导出、引擎退出和更新过程日志，原生宿主启动故障也能写入日志文件。
- 适配新版 ChatGPT 内置 Codex CLI 的位置，兼容应用改名及非默认安装位置，刷新时重新发现应用。
- 修复浮窗详情和消耗弹窗的定位与滚动，拖动位置在重启后保留；账号切换时清理旧账号额度缓存并重新连接。

Windows、Apple Silicon 和 Intel 安装包均由 GitHub Actions 构建。日志和历史仍保存在本机；升级不会自动合并不同设备的历史记录。

请先退出旧版再安装。Mac 安装包为 ad-hoc 签名，未进行 Apple 公证；当前通过下载安装包手动安装，不会自动替换正在运行的 .app。
