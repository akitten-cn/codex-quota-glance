# Codex Taskbar 0.2.3

- Windows 与 macOS 版本统一为 0.2.3。
- 详情左侧新增今日模型用量：只列当天有实际消耗的模型，显示 K/M/B Token 和美元 API 等价估算。总量按输入＋输出计算，缓存不重复叠加。
- 模型汇总保存到 SQLite，重启回扫避免重复累计；未知价格明确标注，不显示虚假的零金额。
- Windows 新增正式安装包（下载文件名包含 `windows-x64-setup.exe`），提供开始菜单入口、可选桌面快捷方式及卸载入口，卸载保留个人设置与历史。
- Windows WebView2 缓存改到 LocalAppData，避免在程序旁或桌面生成缓存文件夹。
- Mac 保留逻辑分辨率适配、拖拽安装与应用图标；提供 Apple Silicon（arm64）和 Intel（x86_64）安装包。

请先退出旧版再安装。Mac 仍为 ad-hoc 签名，未进行 Apple 公证。金额为 API 等价估算，不是订阅账单；价格目录自动同步尚未实现。
