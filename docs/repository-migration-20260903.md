按用户要求沿用 `akitten-cn/codex-quota-glance`，将当前 Rust/WebView2 软件作为主线，旧版单独保留。

## 保留范围

- 旧远端 `main`：`a3653d0071a4d7fbd6b0c4eb8adb2bc9d5e76d2a`。
- 旧版分支：`archive/electron-before-rust-20260903`；在旧提交之上保存旧工作区的五个源码/测试文件变更。
- 原有功能分支和 Release 不删除；新主线是旧主线的后续提交，不重写历史。
- 本地旧源码目录不切换分支、不清理，其未提交修改仍原样保留。
- 当前软件只提交源码、锁文件、脚本与文本设计文档。不上传构建产物、数据库、运行日志、浏览器缓存和本机截图。

## 后续双平台边界

统计口径、持久化模型、数据适配和界面尽量共享；窗口与系统集成按平台隔离。Windows 保持任务栏模式，macOS 新建桌面浮窗宿主。

当前非 Windows 运行入口仍返回不支持。后续需要适配 WKWebView/窗口生命周期、文件与 CLI 定位、显示器、代理和安装更新，再由 macOS 构建机生成测试包，由用户完成 Mac 实机验收。本次迁移不宣称完成这些功能。

共享逻辑的修复会进入两端下一次构建，平台特有问题单独修复；每个平台仍需回归测试。两台设备使用各自本地数据库，不默认同步个人数据。
