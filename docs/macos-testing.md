# Mac 桌面浮动版 · 测试说明

这是 macOS 首个适配测试版，不替换 Windows 任务栏版。设置和详情均为同一个应用的内部窗口；Rust 数据辅助进程随主应用退出。

## 安装

- Apple Silicon（M1/M2/M3/M4 等）：选择 arm64；Intel：选择 x86_64。
- 最低部署目标为 macOS 12；最低版本兼容性仍需实机验证。
- 打开 DMG，将 `Codex Taskbar.app` 拖到“应用程序”后打开；ZIP 解压后也可移动到“应用程序”。
- 当前只有 ad-hoc 临时签名，没有 Developer ID 与 Apple 公证。系统可能拦截：只有确认安装包来源和校验值可信后，才考虑在“系统设置 → 隐私与安全性”中对该应用单独允许。不要全局关闭系统安全检查。
- 本机须有已登录的 Codex。程序尝试 PATH、Homebrew 及 Codex.app 内的 CLI；无法找到 CLI 时，额度不可用，但仍读取本机 `.codex/sessions` 和数据库。终端能运行 `codex app-server --help` 后重新打开应用。

## 交互

- 胶囊可直接拖动，单击展开/收起详情；右键显示设置、重新定位、退出菜单。
- 菜单栏的 `◉` 是另一入口；不显示 Dock 图标。
- 点击详情外部会关闭详情；新消耗弹窗不会关闭详情或设置。
- 设置顶部 26pt 空白区域可拖动；关闭按钮位于右上角。点击“保存并应用”写入 SQLite，再次打开应保留。
- 无副屏时回退主屏；屏幕发生变化时重新夹紧窗口，并重新计算偏移上限。
- 退出会保存本机账本并关闭 Rust 数据进程。

## 数据与限制

- 统计和详情 JSON 与 Windows 共用：输入含缓存，合计=输入+输出；缓存命中率=缓存输入/输入。
- 使用本机 `~/Library/Application Support/CodexTaskbar/codex-taskbar.db`，不自动合并 Windows 的历史记录。Codex 数据目录支持 `CODEX_HOME`。
- 日志与脱敏诊断仅保存在该应用目录。诊断不包含认证凭据、Prompt 或回复。
- 检查/下载更新目前打开 GitHub 发布页，**尚不支持 Mac 自动安装更新或分块下载**。
- Mac 常驻窗口用系统玻璃背景与 WKWebView，需实测 Retina、75/120Hz、休眠唤醒及全屏空间；构建机冒烟不等于这些体验已通过。

## 请验收

1. 首次打开与退出重开：胶囊可见，位置合理，无黑边/假数据闪现。
2. 连续发起 Codex 请求：本次弹窗正确；今日输入/缓存/输出及命中率同步。
3. 5h 有/无、额度耗尽、余额有/无等真实账户情况正确，不伪造缺失数据。
4. 详情三个趋势页与悬停点位；设置按钮；点击外部关闭。
5. 宽度 200/283/440/620、透明度、偏移保存，关闭设置和重启软件后仍保留。
6. 拖拽、单/双显示器、不同缩放、显示器断开后的窗口可见性。
7. 菜单退出后无残留 UI/数据引擎；与 Windows 同时使用互不影响。
