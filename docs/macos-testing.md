# Mac 桌面浮动版 · 测试说明

这是 macOS 适配测试版（0.2.2），不替换 Windows 任务栏版。设置和详情均为同一个应用的内部窗口；Rust 数据辅助进程随主应用退出。

## 安装

- Apple Silicon（M1/M2/M3/M4 等）：选择 arm64；Intel：选择 x86_64。
- 最低部署目标为 macOS 12；最低版本兼容性仍需实机验证。
- 打开 DMG，将左侧 `Codex Taskbar` 拖到右侧 `Applications`（应用程序）快捷方式，安装完成后推出磁盘；ZIP 解压后也可移动到“应用程序”。
- 应用与挂载后的安装磁盘使用自有青紫胶囊图标，覆盖 16–1024 像素 Retina 尺寸。下载的 `.dmg` 文件本身可能仍显示系统磁盘镜像图标，这是 Finder 文件类型图标，不影响应用图标。
- 当前只有 ad-hoc 临时签名，没有 Developer ID 与 Apple 公证。系统可能拦截：只有确认安装包来源和校验值可信后，才考虑在“系统设置 → 隐私与安全性”中对该应用单独允许。不要全局关闭系统安全检查。
- 本机须有已登录的 Codex。程序通过运行中的全部 Codex/ChatGPT 和 Launch Services 获取实际安装位置，按应用身份识别改名的客户端；同时检查系统/用户 Applications、登录 Shell PATH 和 Homebrew 等位置。优先检查新版 ChatGPT 的 `Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex` 和 `codex-cli/bin/codex`，保留旧 `Resources/codex`，并在 Resources 内限量查找其他嵌套 CLI。探测在后台进行，单个候选最多等待 8 秒；失败后约 30 秒重试，点击刷新会重新获取应用位置，后打开 Codex 时也会更新位置。只使用 Codex 自己的账号接口，不复制 OAuth 或 Cookie。

## 交互

- 胶囊可直接拖动，单击展开/收起详情；右键显示设置、重新定位、退出菜单。未激活时允许首击响应，无需先点击激活。
- 菜单栏的 `◉` 是另一入口；不显示 Dock 图标。
- 点击详情外部会关闭详情；新消耗弹窗不会关闭详情或设置。
- 消耗提示、详情和设置按胶囊所在屏幕的可用区域自动选择上方或下方，保留 10pt 间隔；空间不足时缩小窗口供内容滚动。消耗提示的箭头跟随方向翻转，拖动胶囊或更换屏幕时重新定位。
- 设置顶部 26pt 空白区域可拖动；关闭按钮位于右上角。点击“保存并应用”写入 SQLite，再次打开应保留。
- 自由悬浮，不提供停靠方向、目标显示器或边缘偏移。拖动结束保存位置，重启、调整外观时保留位置；屏幕断开或工作区变化时只进行可见范围保护。右键“重新定位浮窗”可恢复初始位置。
- 退出会保存本机账本并关闭 Rust 数据进程。

## 数据与限制

- 统计和详情 JSON 与 Windows 共用：输入含缓存，合计=输入+输出；缓存命中率=缓存输入/输入。
- 使用本机 `~/Library/Application Support/CodexTaskbar/codex-taskbar.db`，不自动合并 Windows 的历史记录。Codex 数据目录支持 `CODEX_HOME`。
- 日志与脱敏诊断仅保存在该应用目录。`logs/codex-taskbar.jsonl.*` 记录引擎启动、连接状态、设置保存、诊断导出和退出；`logs/codex-taskbar.jsonl.host.*` 记录原生宿主启动/引擎启动失败和更新事件。默认 Info 下启动就会写入日志；Off 关闭日志（原生宿主取得设置前的启动故障仍使用默认等级）。诊断不包含认证凭据、Prompt 或回复。
- 诊断包含候选总数、实际存在的候选数、识别到的应用包数量、是否配置手动路径、探测成功/失败/超时及连接状态；不会记录完整路径、Shell 输出、邮箱或认证值。详情与设置同步显示连接失败原因。`existing_candidates: 0` 且 `probes: []` 表示还未找到 CLI，尚未进入账号或额度请求，不能据此判断登录失效。
- 本机运行状态优先使用现有事件/数据库；缺少这些来源时从最新会话的生命周期事件推断状态。该后备不是所有并发会话的完整状态，最长 15 分钟没有生命周期更新时退回空闲。
- 账号与官方额度跟随本机登录：每 2 秒比较 `auth.json` 的元数据，变化后清空旧账号缓存并重建监视器自己的 CLI 连接；手动刷新也会重新加载登录。无登录文件的凭据后端约每 60 秒重新连接。只检查文件元数据，不读取或复制凭据内容；本机今日与历史 Token 仍按设备累计。
- “检查更新”在应用内请求 GitHub，按系统代理/PAC 连接；“下载并打开安装包”选择当前进程架构的 DMG（无 DMG 时使用 ZIP），校验 SHA-256 后打开本地包，仍需手动完成拖放安装。API 返回 403/429 时尝试同一官方 Release 的架构校验清单；不会跳过摘要验证。安装包保存在数据目录 `updates/`。**尚不支持自动替换 .app 或分块下载**。
- Mac 常驻窗口用系统玻璃背景与 WKWebView，需实测 Retina、75/120Hz、休眠唤醒及全屏空间；构建机冒烟不等于这些体验已通过。

## 请验收

1. 首次打开与退出重开：胶囊可见，位置合理，无黑边/假数据闪现。
2. 连续发起 Codex 请求：本次弹窗正确；今日输入/缓存/输出及命中率同步。
3. 5h 有/无、额度耗尽、余额有/无等真实账户情况正确，不伪造缺失数据。
4. 详情三个趋势页与悬停点位；设置按钮；点击外部关闭。
5. 宽度 200/283/440/620、透明度保存，关闭设置和重启软件后仍保留；改变这些设置不重置拖动位置。
6. 拖拽、单/双显示器、不同缩放、显示器断开后的窗口可见性。
7. 菜单退出后无残留 UI/数据引擎；与 Windows 同时使用互不影响。

## 实现对照

- [CodexBar CLI 定位器](https://github.com/steipete/CodexBar/blob/main/Sources/CodexBarCore/CodexExecutableResolver.swift)：登录 Shell PATH 与脚本启动环境。
- [Codex Usage Bar](https://github.com/yizhigou/codex-usage-bar)：同时查找 ChatGPT.app/Codex.app，自带 CLI 读取账号额度。

本项目独立实现上述兼容处理，不引入浏览器 Cookie 获取和跨应用认证文件复制。自动化验证首击接收策略、位置回读、保存/重开和页面布局，不等于真实鼠标或用户账号已完成实机验收。
