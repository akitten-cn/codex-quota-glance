稳定版

检查更新

更新清单和安装包均需校验签名 / SHA-256；下载完成后由更新助手在程序退出后替换文件。

更新检查与安装

每天后台检查一次；发现新版本后显示更新说明，用户确认后下载、安装并重启。

代理与下载加速

自动使用 Windows 系统代理 / PAC若本机代理未启用系统代理，提供明确的自定义代理入口，不猜测端口。
自适应分块下载仅服务器支持 Range 且安装包较大时启用，最多 4 路；失败自动单路重试。

运行诊断

日志写入等级在开发时默认 Debug；分享诊断包前会移除密钥、账户标识、Prompt 和完整线程标识。

日志等级

推荐日常使用 Info；开发或排查问题时切换 Debug。

日志保留

超过限制时在低优先级任务中轮转，避免日志持续占用磁盘。

生成脱敏诊断包包含版本、运行健康度、数据源状态和错误摘要；不含私密内容。
